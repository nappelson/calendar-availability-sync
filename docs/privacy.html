Privacy policy

Nappelson Scripts is a personal-use utility maintained by the GitHub user nappelson. This policy describes the owner's installation and its informational website. Anyone running their own copy controls that separate installation.

Data accessed and purpose

The script accesses the authorized account's verified email identity to confirm that the intended account connected. It reads events from configured calendars, including dates, times, status, titles, descriptions, locations, meeting links, and metadata needed to filter and reconcile events. Event data returned by Google may include attendee information used to determine participation status.

It requests Google Calendar event read/write access to create, update, and remove synchronized copies. This permission is broader than access to only the copies it creates. It does not request Gmail or Drive access.

Data copied between accounts

Accessible event details are copied into the designated hub calendar. Other configured calendars receive private Busy blocks and synchronization metadata, without original titles or descriptions. Copies do not invite attendees. Copied details are subject to the destination calendar's access permissions. This transfer between the owner's configured Google accounts is the purpose of the utility.

Storage and access

Processing runs in Google Apps Script. OAuth client credentials, access and refresh tokens, connection identities, and synchronization state are stored in the private script project's Script Properties, which project editors can access. Calendar selections and account addresses are held in private installation configuration. Copies and ownership metadata are stored in Google Calendar.

Operational logs may contain connection identifiers and sync counts or errors. Setup can print temporary authorization links. These logs and links should be kept private. The public source repository and this website do not contain the owner's calendar configuration or OAuth credentials.

Sharing and limited use

Google user data is used only to provide and maintain the configured calendar synchronization. It is not sold, used for advertising, or used to train generalized AI or machine learning models. Calendar data is processed through Google's services; this informational website does not receive it.

Nappelson Scripts's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention, disconnection, and deletion

Synchronization state and credentials remain until removed from the installation. To uninstall cleanly, stop scheduling and run the script's cleanup procedure while access is still available, then disconnect accounts and revoke the app in Google Account connections. Delete the Apps Script project and any private local configuration or backups when no longer needed.

Revoking access or stopping the script alone does not delete existing calendar copies. Copies that cannot be cleaned up by the script must be removed manually. Google's services govern any remaining service logs and retention.

Website hosting

This static site uses GitHub Pages and includes no analytics scripts, forms, or account sign-in. GitHub may collect visitor information, including IP addresses, for security and service operation under the GitHub Privacy Statement.

Questions and changes

Contact the maintainer through the project issue tracker using a general description only; it is public. Do not post private account or event data. Changes to this policy will be published here with an updated date.
